# Быстрое дообучение YOLO11s для SmartFridge

Этот комплект нужен, чтобы повысить точность распознавания именно тех упаковок и пластиковых макетов, которые снимает ESP32-CAM. Он **не меняет Android-приложение и не заменяет текущую модель**, пока новая модель не обучена и не проверена.

## Важно перед стартом

В репозитории есть `best.tflite`, но нет исходного `.pt`, датасета и исходного `data.yaml`. Поэтому сейчас нельзя безопасно продолжить обучение именно текущих весов: TFLite — формат для запуска, а не нормальный исходник для fine-tuning.

Скрипт ниже по умолчанию обучает YOLO11s от официальных предобученных весов `yolo11s.pt`. Если у тебя сохранился исходный `best.pt` от той же модели с теми же 17 классами и в том же порядке, передай его через `--weights`. Не используй случайный `best.pt` от другой модели.

## Шаг 1. Собери фотографии

Для быстрого первого прохода:

- Начни с проблемных классов: **Шоколад, Молоко, Сухофрукты, Сушёные продукты**.
- Для каждого класса собери хотя бы 30–50 разных фотографий; лучше 100+.
- Фотографируй именно те пластиковые макеты и упаковки, которые потом будут перед камерой SmartFridge.
- Меняй расстояние, угол, фон и освещение. Добавь кадры с несколькими предметами одновременно.
- Не делай 50 копий одной фотографии: нужны разные реальные кадры.
- Чтобы модель не забыла остальные классы, добавь в набор примеры всех 17 классов. Для первого рабочего набора стремись хотя бы к 20–30 разным фото на каждый класс.

Раздели исходные фотографии **до** аугментаций:
- 80% — train;
- 20% — val.

## Шаг 2. Разметь объекты

Используй CVAT или Roboflow Annotate и экспортируй датасет в формат **YOLO Detection** (не Classification).

На каждой фотографии нарисуй прямоугольник вокруг каждого отдельного продукта. Выбери класс строго по списку ниже. Если на фото шоколад и молоко — должно быть две рамки с двумя соответствующими классами.

Порядок классов фиксированный и должен совпадать с Android-кодом:

0. Алкоголь
1. Конфеты
2. Консервы
3. Шоколад
4. Десерт
5. Сушёные продукты
6. Сухофрукты
7. Напитки
8. Жвачка
9. Растворимые напитки
10. Лапша быстрого приготовления
11. Молоко
12. Средства гигиены
13. Снеки
14. Приправы
15. Канцелярия
16. Бумажные салфетки

## Шаг 3. Разложи датасет

Папки должны выглядеть так:

```
dataset/
  images/
    train/
      image001.jpg
      image002.jpg
    val/
      image101.jpg
  labels/
    train/
      image001.txt
      image002.txt
    val/
      image101.txt
```

У каждого изображения должен быть одноимённый TXT-файл с YOLO-разметкой. Допустимы пустые TXT для кадров без объектов.

## Шаг 4. Запусти обучение

Самый быстрый вариант — Google Colab с GPU (Runtime → Change runtime type → T4 GPU), либо компьютер с NVIDIA GPU.

В Google Colab сначала включи GPU: Runtime → Change runtime type → T4 GPU. Затем выполни:

```bash
!git clone -b smartfridge-2-redesign https://github.com/Bobronchik/SmartFridge2.git
%cd SmartFridge2
!pip install -r training_yolo11s/requirements.txt
```

Загрузи папку `dataset` в корень проекта (в Colab — в `/content/SmartFridge2/dataset`), чтобы рядом с папками `app` и `training_yolo11s` появилась папка `dataset`. Затем запусти:

```bash
!python training_yolo11s/train_yolo11s.py --dataset ./dataset
```

Если у тебя есть оригинальный checkpoint именно этой 17-классовой модели, загрузи его в корень проекта и запусти:

```bash
!python training_yolo11s/train_yolo11s.py --dataset ./dataset --weights ./best.pt
```

Скрипт проверит структуру датасета, ID классов и разметку, обучит модель, выполнит validation и экспортирует TFLite 640×640. Он остановится, если в train отсутствует один из 17 классов.

## Шаг 5. Проверь результат и подключи

1. Сначала сравни метрики validation и изображения из папки `runs/smartfridge/`.
2. Проверь отдельно шоколад, молоко, сухофрукты и сушёные продукты на фотографиях, которых не было в train/val.
3. Не заменяй рабочую модель, если новая путает классы чаще.
4. Если результат лучше, скопируй экспортированный TFLite-файл в:
   `app/src/main/assets/best.tflite`
   с именем `best.tflite`.
5. Пересобери и установи Android-приложение.

**Не меняй размер входа 640 на телефоне отдельно от модели.** Скрипт экспортирует ту же форму 640×640, которую сейчас ожидает `YOLODetector.kt`.

## Что важно для точности

- Разметка важнее количества синтетических копий. Неправильные классы в TXT испортят модель.
- Не помещай один и тот же снимок или почти одинаковые кадры одновременно в train и val.
- Сохраняй примеры всех классов, иначе модель может забыть ранее распознаваемые продукты.
- Не считай высокую confidence доказательством правильного класса. Смотри confusion matrix и проверяй отдельные фотографии.
- Никакая настройка сама по себе не исправит плохой датасет или неверный порядок class ID.
